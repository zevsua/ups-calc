# Калькулятор ДБЖ (Android)

Офлайн-калькулятор системи безперебійного живлення: підбір інвертора, збірка акумулятора (S×P), BMS, запобіжник, кабель, зарядка, кошторис і список покупок.

## Як встановити
1. Відкрийте на телефоні сторінку **Releases** цього репозиторію (праворуч) → остання версія.
2. Завантажте `Kalkulyator-DBZh.apk`.
3. Відкрийте файл і дозвольте встановлення з цього джерела.

Нові версії ставляться поверх старої, введені дані зберігаються.

## Як оновити
Змініть `app/src/main/assets/index.html` і зробіть push у `main` — GitHub Actions збере новий APK і викладе його в Releases.
